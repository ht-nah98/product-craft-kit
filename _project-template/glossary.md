## Quy ước đặt tên (Naming Conventions)

### User Stories
```
US-[MODULE]-[NUMBER]
Ví dụ: US-AUTH-001
```

### Epics
```
EPIC-[MODULE]-[NUMBER]
Ví dụ: EPIC-AUTH-001
```

### Bugs
```
BUG-[NUMBER]
Ví dụ: BUG-042
```
