# Workflow: Viết PRD

## Khi nào dùng
Khi user cần viết tài liệu yêu cầu sản phẩm/tính năng tổng quan.

## Steps

### 1. Xác định project
- Hỏi hoặc xác định project đang làm việc

### 2. Đọc context
Đọc các file:
1. `_master/skills/SKILL_write-prd.md`
2. `projects/[project]/project-context.md`
3. Các PRD/Epics đã có (nếu có)

### 3. Thu thập thông tin từ user
- Problem statement: Vấn đề gì cần giải quyết?
- Target users: Ai sẽ dùng?
- Business goals: Mục tiêu kinh doanh?
- Success metrics: Đo lường thành công bằng gì?
- Scope: In-scope và out-of-scope?
- Timeline: Deadline?

### 4. Viết PRD
Tuân thủ template được reference trong skill:
- Overview & Problem Statement
- Goals & Non-Goals
- User Stories tổng quan
- Functional Requirements
- Non-Functional Requirements
- Timeline

### 5. Lưu file
Lưu vào:
- `projects/[project]/docs/1_business_docs/prd/[prd-name].md`

### 6. Suggest next steps
- Break down thành Epics
- Viết User Stories chi tiết
- Tạo Backlog

## Output
- File PRD hoàn chỉnh
- Ready cho stakeholder review
