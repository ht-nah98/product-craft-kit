# Workflow: Discovery Phase

> Bắt đầu Phase 1 của Product Building - Hiểu vấn đề trước khi giải quyết

## Các bước thực hiện

### 1. Đọc Skill
// turbo
Đọc file: `.agent/skills/product_discovery/SKILL.md`

### 2. Đọc Template
// turbo
Đọc file: `.agent/resources/templates/06_product_building/_template_discovery.md`

### 3. Đọc Project Context (nếu có)
Nếu user đã có project:
- Đọc `projects/[project]/project-context.md`
- Đọc `projects/[project]/glossary.md`

Nếu chưa có project:
- Hỏi user tên project
- Tạo project mới theo `/new-project`

### 4. Hỏi thông tin để lập Research Plan
Cần hỏi user:
1. Đối tượng nghiên cứu là ai? (Target users)
2. Muốn tìm hiểu điều gì? (Research objectives)
3. Đã có giả định nào cần validate?
4. Có data nào sẵn có không?

### 5. Tạo Discovery Document
Dùng template tạo file:
`projects/[project]/docs/6_product_building/phase1_discovery.md`

### 6. Confirm với user
Xác nhận research plan với user trước khi tiến hành
