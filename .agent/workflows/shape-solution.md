# Workflow: Shape Solution Phase

> Phase 3 của Product Building - Design giải pháp "shaped" (vừa đủ)

## Các bước thực hiện

### 1. Đọc Skill
// turbo
Đọc file: `.agent/skills/solution_shaping/SKILL.md`

### 2. Đọc Template
// turbo
Đọc file: `.agent/resources/templates/06_product_building/_template_solution_shape.md`

### 3. Đọc Problem Canvas
// turbo
Đọc file problem từ Phase 2:
`projects/[project]/docs/6_product_building/phase2_problem_canvas.md`

### 4. Solution Brainstorming
Hỏi user và cùng brainstorm:
1. Có những cách nào giải quyết problem này?
2. Competitors đang làm gì?
3. Thử nghĩ crazy ideas?
4. Simplest possible solution là gì?

### 5. Evaluate Options
Dùng criteria trong skill để đánh giá:
- Solves problem effectively
- Fits appetite
- User adoption
- Technical feasibility
- Scalability

### 6. Shape Solution
Tạo shaped solution document:
`projects/[project]/docs/6_product_building/phase3_solution_shape.md`

Bao gồm:
- Solution sketch
- User flow
- Rabbit holes (risks)
- No-gos (out of scope)
- Nice-to-haves

### 7. Get Betting Approval
Yêu cầu team "bet" on this solution trước khi build
