# Workflow: Launch Checklist

> Phase 4 của Product Building - Checklist trước khi ship

## Các bước thực hiện

### 1. Đọc Skill
// turbo
Đọc file: `_master/skills/2_product_building/SKILL_build-and-ship.md`

### 2. Đọc Template
// turbo
Đọc file: `_master/templates/06_product_building/_template_launch_checklist.md`

### 3. Prepare Checklist

Dùng template tạo launch checklist:
`projects/[project]/docs/6_product_building/phase4_launch_checklist.md`

### 4. Review với Team

#### Technical Checklist
- [ ] Core functionality working
- [ ] Error handling in place
- [ ] Logging và monitoring
- [ ] Performance acceptable
- [ ] Security review

#### User Experience
- [ ] Onboarding clear
- [ ] Documentation ready
- [ ] Feedback mechanism
- [ ] Known limitations documented

#### Operations
- [ ] Deployment process documented
- [ ] Rollback plan ready
- [ ] Support team briefed
- [ ] Success metrics tracked

### 5. Go/No-Go Decision

Collect votes từ stakeholders:
- Product Owner
- Tech Lead
- Ops/DevOps

### 6. Launch và Monitor

Nếu GO:
- Execute launch
- Monitor first 24-48 hours
- Collect initial feedback

Schedule learning review cho Phase 5.
