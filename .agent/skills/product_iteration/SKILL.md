## Product Building Phase 5 - Grow & Iterate

## Mục Đích

Skill này hướng dẫn thực hiện Phase 5 "SCALE" - giai đoạn iterate based on learnings và grow product towards Product-Market Fit.

### Goals của Phase này:
- ✓ Analyze learnings từ MVP
- ✓ Decide: Continue, Pivot, or Kill
- ✓ Plan next iterations
- ✓ Scale what's working

**OUTPUT**: Iteration plan + Growth roadmap

## Quy Trình Thực Hiện

### Bước 1: Analyze Learnings

**From Phase 4, gather:**
1. Quantitative metrics vs targets
2. Qualitative feedback themes
3. Usage patterns
4. Support tickets / complaints

**Framework: What Worked / What Didn't / What's Next**

| Category | What Worked | What Didn't | Insight |
|----------|-------------|-------------|---------|
| Feature A | High usage | - | Double down |
| Feature B | - | Confusing | Redesign or cut |
| Feature C | Some usage | Performance | Optimize |

### Bước 2: Make Go/No-Go Decision

**Decision Framework:**

```
┌─────────────────────────────────────────────┐
│ Did users engage with the product?          │
│                                             │
│   YES → Did it solve their problem?         │
│         │                                   │
│         ├─ YES → CONTINUE & SCALE           │
│         │                                   │
│         └─ NO → PIVOT (change solution)     │
│                                             │
│   NO → Did they understand it?              │
│        │                                    │
│        ├─ NO → PIVOT (change approach)      │
│        │                                    │
│        └─ YES → KILL (wrong problem)        │
└─────────────────────────────────────────────┘
```

### Bước 3: Plan Next Iteration

**If CONTINUE:**

Prioritize improvements:
1. **Fix**: Critical bugs/issues
2. **Improve**: Top user requests
3. **Expand**: New use cases

Use same cycle: Shape → Build → Ship → Learn

**Iteration Size:**
| Type | Duration | Focus |
|------|----------|-------|
| Quick Fix | 1 week | Bugs, small improvements |
| Enhancement | 2-3 weeks | Feature improvements |
| New Feature | 4-6 weeks | Major additions |

**If PIVOT:**

Go back to Phase 1 or 2:
- Same problem, different solution → Phase 3
- Different problem → Phase 1

**If KILL:**

Document learnings for future:
- What we learned
- Why it didn't work
- What to avoid next time

### Bước 4: Scale What's Working

**When to scale:**
- Consistent positive metrics
- Users asking for more
- Clear retention

**Scaling activities:**
1. **Expand audience**: More user segments
2. **Expand features**: Based on feedback
3. **Improve operations**: Reduce manual work
4. **Build moat**: Defensibility

## Build → Measure → Learn Loop

Phase 5 is ongoing. Each iteration:

```
       ┌──────────────┐
       │    BUILD     │
       │ (next cycle) │
       └──────┬───────┘
              │
              ▼
       ┌──────────────┐
       │   MEASURE    │
       │  (metrics)   │
       └──────┬───────┘
              │
              ▼
       ┌──────────────┐
       │    LEARN     │
       │  (insights)  │
       └──────┬───────┘
              │
              ▼
       [Back to BUILD]
```

## Product-Market Fit Indicators

**Signs you have PMF:**
- 40%+ would be "very disappointed" without product
- Organic word-of-mouth growth
- Users returning without prompting
- Clear monetization potential

**Signs you don't have PMF:**
- High churn
- Users need convincing
- Flat/declining usage
- Negative NPS

## Completion Checklist

```
□ Learnings from MVP analyzed
□ What worked / didn't documented
□ Clear decision made (Continue/Pivot/Kill)
□ Next iteration planned (if continuing)
□ Team aligned on direction
□ Resources allocated
□ Success criteria for next cycle defined

ONGOING:
□ Regular learning reviews (weekly/bi-weekly)
□ Metrics dashboard maintained
□ User feedback continuously collected
□ Iteration backlog groomed
```
